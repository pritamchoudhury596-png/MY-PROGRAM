# 🚀 CORE PYTHON ARCHITECTURE & UTILITIES

Welcome to my core repository. This project showcases a collection of optimized, secure, and standalone Python utilities integrated with local database management systems. Designed with clean object-oriented logic, these tools emphasize performance and local stability.

---

## 🛠️ Key Features & Projects

### 1. JarvisCore (`jarvis.py`)
*   **Architecture:** Object-Oriented Programming (OOP) based implementation.
*   **Database:** Structured local storage powered by **SQLite3** (`memory.db`).
*   **Reliability:** Built-in auto-commit mechanism (`self.conn.commit()`) with advanced local exception handling designed to prevent data corruption.

### 2. Custom Security & Calculators
*   **Voice Authentication:** Euclidean distance math model for secure access validation.
*   **Mathematical Utilities:** Kinetic Energy calculators, temperature converters, custom math engines, and high-performance string multipliers.
